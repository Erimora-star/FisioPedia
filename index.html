Puedes pegar el objeto directamente desde la consola de Firebase. La app extraerá automáticamente los campos necesarios.

💡 Firebase es 100% gratuito para proyectos estudiantiles y de aula.

No requieres tarjeta de crédito ni planes de pago para usar Cloud Firestore y Autenticación.

  1. Crea tu proyecto: Entra a Firebase Console, inicia sesión con tu cuenta de Google y haz clic en "Agregar proyecto" (nómbralo FisioPedia).
  2. Habilita Cloud Firestore: En el menú lateral izquierdo, ve a Compilación > Firestore Database y haz clic en "Crear base de datos". Selecciona "Empezar en modo de prueba" y pulsa Habilitar.
  3. Activa Autenticación Anónima: Ve a Compilación > Authentication > Comenzar > Sign-in method, haz clic en "Anónimo" y márcalo como Habilitado. Esto permite que cada usuario tenga su propio baúl de favoritos en la nube sin tener que recordar contraseñas.
  4. Registra tu Aplicación Web: Ve al icono de engranaje (⚙️ Configuración del proyecto) en la parte superior izquierda. En la pestaña General, baja hasta la sección "Tus apps" y haz clic en el icono Web (</>). Asigna el nombre FisioPedia Web y pulsa Registrar app.
  5. Copia el bloque firebaseConfig: Verás un bloque de código como este: 
    const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "tu-fisiopedia.firebaseapp.com",
  projectId: "tu-fisiopedia",
  ...
};
  6. Pégalo en Fisio Pedía: Vuelve a la pestaña "Configurar Credenciales" de este modal, pega el código copiado y haz clic en Guardar y Conectar. ¡Y listo! Tu app quedará conectada a la nube en tiempo real.
🛡️ Reglas recomendadas para Firestore (Seguras)

En Firebase Console > Firestore Database > pestaña Reglas, puedes pegar esto para que cada estudiante solo acceda a su propia información:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /system_check/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}
